## 1. Project Overview

**Follow Me** is an open-source Edge AI Computer Vision project focused on human detection, person re-identification, and target tracking.

The project aims to research, develop, and optimize AI models that enable edge devices to detect and identify individuals in real-world environments with limited computational resources.

Follow Me emphasizes practical AI model development, performance evaluation, and the integration of multiple Computer Vision technologies into reusable software components.

The project follows an incremental development approach, starting with AI model research and fine-tuning, followed by vision pipeline development, edge optimization, and real-world hardware integration.

### Primary Objectives

- **AI Model Development:** Research, fine-tune, and evaluate AI models for human detection and person re-identification.
- **Performance Benchmarking:** Conduct reproducible experiments to evaluate model accuracy, inference speed, and computational efficiency.
- **Vision Pipeline Development:** Integrate detection, re-identification, and tracking technologies into a functional Computer Vision pipeline.
- **Edge AI Optimization:** Optimize AI inference for edge devices with limited computational resources.
- **Open-source Contribution:** Publicly release trained models, source code, training configurations, benchmark results, and technical documentation to support further research and development.

### Project Scope

Follow Me primarily focuses on AI research, model development, and Computer Vision software.

The project will initially concentrate on improving existing pretrained models through fine-tuning and systematic evaluation. These models will subsequently be integrated into a unified Vision Pipeline and organized into reusable software components.

Framework-level architecture and additional extensibility features may be introduced as the project evolves and practical requirements emerge.

Hardware development is considered a secondary objective, serving as a platform for demonstrating and evaluating the developed AI technologies in real-world applications, particularly autonomous following robots.

### Development Philosophy

Follow Me follows an incremental and research-driven development philosophy:

1. **Research First:** Evaluate existing technologies before developing new solutions.
2. **Performance-driven:** Prioritize measurable improvements supported by reproducible benchmarks.
3. **Modular Development:** Build software components that can be reused and extended when necessary.
4. **Edge-first Design:** Prioritize efficient local inference on resource-constrained devices.
5. **Open Development:** Share research findings, trained models, source code, and documentation with the public.

**The ultimate goal of Follow Me is to develop practical, efficient, and reusable Edge AI Computer Vision technologies that can be adopted and extended by other developers and researchers.**
